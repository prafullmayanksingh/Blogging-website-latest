# Contributing

Thanks for your interest in improving Student Blog.

## Before you start

- Check existing issues and pull requests to avoid duplicating work.
- For a significant change, open an issue first to discuss the approach.
- Keep changes focused and preserve the existing HTML, CSS, and JavaScript conventions.

## Submit a change

1. Fork the repository and create a branch for your change.
2. Make and test your changes locally.
3. Open a pull request describing what changed and how you tested it.

## Test locally

Serve the `public/` directory with a local web server, then check the affected pages and interactions in a browser. For example:

```powershell
python -m http.server 8000 --directory public
```

There is currently no automated test suite.

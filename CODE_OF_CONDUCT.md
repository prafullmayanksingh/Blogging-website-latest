# Code of Conduct

## Our commitment

We want this project to be a welcoming and respectful space for everyone, regardless of background or experience.

## Expected behavior

- Be considerate, respectful, and constructive.
- Discuss ideas and feedback without personal attacks or harassment.
- Respect differing viewpoints and experiences.
- Focus on what is best for the project and its community.

## Unacceptable behavior

Harassment, discrimination, intimidation, abusive language, and publishing another person's private information without permission are not acceptable.

## Responsibility and reporting

Project maintainers may remove, edit, or reject contributions that violate this code and may limit participation when necessary. Report concerns privately to a maintainer through GitHub rather than in a public discussion.
